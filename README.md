# Campus Study Planner

**Created by Suhaib Ahmad**

## Project Description

Campus Study Planner is a website I created for my CISC108 final project. I made this website to help students organize their school assignments and manage their study time.

Students can add assignments, choose their classes, mark assignments as completed, and set daily study goals. The website also helps students see their progress and how much work they have left.

## Website Features

1. Add assignments with a name, class, and estimated time.
2. View all assignments in one place.
3. Mark assignments as completed.
4. View assignments from a specific class.
5. Set and change daily study goals.
6. Check how many assignments are finished and how much work is left.

## Programming

I created this website using Python and the Drafter library. I used routes to create different pages and dataclasses to organize information. I also used input fields, loops, and if statements to make the website work.
